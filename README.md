# RSCG Training

## Funktionen
- 19 Stammspieler und Gastspieler
- 8 Teilnehmer, 2 Plaetze, 4 Runden
- Bis zu zwei fixe Teams je Runde
- Restliche Paarungen werden automatisch ausgelost
- Keine wiederholten Partner innerhalb eines Trainings
- Partnerhistorie ueber Wochen im lokalen Browser
- WhatsApp-Export und Druck/PDF

## Lokal starten
```bash
npm install
npm run dev
```

## Vercel
Build Command: `npm run build`  
Output Directory: `dist`
