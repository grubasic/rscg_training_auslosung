# RSCG Training

## Fixpaarungen
Jede Fixpaarung wird einmal angelegt. Im Dropdown **Anzahl Runden** wird festgelegt, ob die Paarung für 1, 2, 3 oder 4 aufeinanderfolgende Runden gilt.

## Start
```bash
npm install
npm run dev
```

## Vercel
- Framework: Vite
- Build: `npm run build`
- Output: `dist`
